DIKSHA (JUMBOO!!) — BIRTHDAY WEBSITE
Made with love by Mohit | Dreamy lavender theme

QUICK START
1. Extract this ZIP file.
2. Open the extracted "diksha_birthday_website" folder in VS Code.
3. Open index.html in a browser. For a better development preview, install the VS Code extension "Live Server", right-click index.html, and select "Open with Live Server".
4. Personalize the timeline text inside index.html with real dates and memories.

ADD YOUR PHOTOS
Put three photos in the photos folder:
  photos/photo1.jpg
  photos/photo2.jpg
  photos/photo3.jpg
Use JPG images with those exact names. You can use your own photos, a favourite picture of Diksha, or photos together. If you use PNG, change the image src path in index.html accordingly. Keep photos private if you do not want them publicly accessible when you publish the site.

ADD “PERFECT” BY ED SHEERAN
The website is configured to play a local MP3 file at:
  music/our-song.mp3
Place an MP3 file you are allowed to use there. Rename it to our-song.mp3. The site tries to start playback when she taps "Open your surprise"; mobile browsers normally require a user tap before music can play.
This ZIP does not include the copyrighted song. If you do not have a permitted MP3, you can instead add a link/embed from an official music service, subject to that service's terms and availability.

PERSONALIZE
- Search for "Diksha", "JUMBOO!!", and "Mohit" in index.html to change names.
- Edit the letter in the section id="letter".
- Edit gift messages in each button with class="gift" (data-title, data-message, data-icon).
- Edit the timeline in section id="memories".
- Edit the final secret message in the JavaScript near "To my JUMBOO!!".

BIRTHDAY DATE
The requested birthday is 13 October 2026. The current version does not show a countdown, so it will remain useful after the birthday too.

PUBLISHING
You can host the folder on a static website host such as GitHub Pages or Netlify. Upload the whole folder contents, including photos/ and music/. Do not upload private photos or personal information unless you are comfortable with the site's privacy settings.
